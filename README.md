## 🌟 About Me
- 근본은 **React**이며, 컴포넌트 구조·상태 설계·UI 인터랙션을 정교하게 다듬는 것을 좋아합니다.  
- Next.js **Pages Router → App Router** 환경 모두 경험했고, 마이그레이션·라우팅 구조 설계·데이터 패칭 전략을 직접 개선해 왔습니다.

- 트래킹(GA4/GTM), SEO, 메타·OG 태그, JSON-LD 등 서비스 전반의 **검색·로그·지표 시스템**을 설계·운영합니다.  
- 팀과 프로젝트를 위한 코드·UI·구조를 **정돈·단순화·표준화**하는 데 강점이 있습니다.
